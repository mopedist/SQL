###  Адвокатская контора.

**- Информация об адвокатах:** ФИО, адрес, телефон, стаж работы, специализация, список дел;

**- Информация о клиентах:** ФИО, адрес, паспортные данные, список дел.;

**- Дела:** номер, дата начала, дата конца, клиент, адвокаты, максимальный срок, полученный срок (условный/реальный), сумма штрафа (учесть, что одного клиента могут защищать несколько адвокатов).;

**Реализовать:**
- Получение списка текущих клиентов для конкретного адвоката;
- Получение списка дел для адвоката
- Поиск «постоянных клиентов» (те, которые проходили > 1 раза по разным делам)
- Определение наиболее квалифицированных адвокатов (например, по параметрам максимальный срок минус полученный срок с учётом оправданий, условных сроков и штрафов).

реляционную модель данных и отобразить ее в виде списка сущностей с их атрибутами и типами атрибутов, 
для атрибутов указать, явл. ли он первичным или внешним ключом
