###  Адвокатская контора.

**- Информация об адвокатах:** название, адрес, телефон, ФИО руководителя,  ФИО секретаря, список общефакультетских помещений;

**- Информация о клиентах:** название, адрес, телефон, ФИО руководителя,  ФИО секретаря, список помещений кафедры;

**- Дела:** ФИО,  должность(лаборант, ассистент, преподаватель, старший преподаватель, доцент, профессор), паспорт, телефон;

**Реализовать:**
- Получение списка текущих клиентов для конкретного адвоката;
- Получение списка дел для адвоката
- Поиск «постоянных клиентов» (те, которые проходили > 1 раза по разным делам)
- Определение наиболее квалифицированных адвокатов (например, по параметрам максимальный срок минус полученный срок с учётом оправданий, условных сроков и штрафов).
